## Описание курса

Курс формирует практические навыки разработки веб-приложений на всех уровнях архитектуры:
от низкоуровневого сетевого взаимодействия на сокетах до современных распределенных REST API и клиентских SPA-интерфейсов.

## Навигация по работам

- [**Лабораторная работа №1: Работа с сокетами**](labs/lab1/lab1.md)
  - *Задание 1:* Обмен сообщениями по протоколу UDP.
  - *Задание 2:* TCP клиент-сервер вычислений (Вариант 2: Квадратное уравнение $ax^2 + bx + c = 0$).
  - *Задание 3:* Отдача HTML-страницы по HTTP/1.1 через сокеты.
  - *Задание 4:* Многопользовательский чат на TCP с использованием `threading`.
  - *Задание 5:* Полнофункциональный веб-сервер с обработкой GET/POST запросов (Журнал оценок).
